# KNOWN Platform — React + Vite

Premium frontend foundation for the KNOWN Experience Summit, inspired by the visual world of **Before the Ground Forgets** and the KNOWN reflective card game.

## Included

- KNOWN gold tree identity throughout the interface
- Book-cover storytelling hero
- Premium black, ember-gold and ivory visual system
- Private-individual and organisation-representative support paths
- Supabase submission through `submit_support_request`
- Automatic KN reference handling
- WhatsApp handoff after the record is saved
- Responsive layouts for desktop, tablet and mobile

## Vercel environment variables

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Local setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
